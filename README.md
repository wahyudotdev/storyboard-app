# storyboard-app

Public site for the Storyboard Chrome extension, served with GitHub Pages:

- https://wahyudotdev.github.io/storyboard-app/ (landing page)
- https://wahyudotdev.github.io/storyboard-app/privacy/ (privacy policy, linked from the Chrome Web Store listing)

Plain HTML and CSS, no build step. Update the effective date in `privacy/index.html` whenever the policy changes.
